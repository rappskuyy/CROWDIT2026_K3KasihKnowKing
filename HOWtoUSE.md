# Cara Menggunakan Safe School Hub

## Informasi Penting

Safe School Hub versi demo saat ini menggunakan **Local Storage** pada browser untuk menyimpan data pendaftaran. Data yang Anda masukkan **tidak dikirim ke server** dan hanya tersimpan di perangkat yang digunakan.

Karena itu, Anda dapat menggunakan data bebas untuk mencoba platform.

---

## Cara Mendaftar

1. Buka halaman pendaftaran Safe School Hub.
2. Isi formulir pendaftaran:

   * Nama Lengkap
   * Email
   * Nama Sekolah
   * Nomor Telepon
3. Klik tombol **Daftar Gratis Sekarang**.

---

## Ketentuan Pengisian Data

### Nama Lengkap

Anda dapat mengisi nama apa saja.

**Contoh:**

* Budi Santoso
* Test User
* Admin Demo

### Email

Anda dapat menggunakan email apa saja, namun **harus mengandung simbol `@`** agar lolos validasi sistem.

**Contoh yang valid:**

* [budi@gmail.com](mailto:budi@gmail.com)
* [test@demo.com](mailto:test@demo.com)
* [user@sekolah.id](mailto:user@sekolah.id)

**Contoh yang tidak valid:**

* budigmail.com
* test.demo
* user123

### Nama Sekolah

Dapat diisi dengan nama sekolah apa saja.

**Contoh:**

* SMP Negeri 1 Jakarta
* SMK Wikrama Bogor
* Sekolah Demo

### Nomor Telepon

Dapat diisi dengan nomor telepon bebas.

**Contoh:**

* 08123456789
* 08987654321

---

## Penyimpanan Data

Data pendaftaran pada versi demo ini:

* Disimpan menggunakan Local Storage browser.
* Tidak tersimpan pada database online.
* Tidak dikirim ke server.
* Akan tetap tersedia selama cache dan data browser tidak dihapus.
* Akan hilang jika Local Storage browser dibersihkan.

---

## Catatan

Website ini dibuat untuk keperluan demonstrasi dan pengembangan Safe School Hub. Oleh karena itu, pengguna tidak perlu menggunakan data pribadi asli saat melakukan pendaftaran.
