# 🏫 Safe School Website - Panduan untuk Dewan Juri

Halo Bapak/Ibu Dewan Juri! Selamat datang di **Safe School Website**. 

Web ini dirancang khusus sebagai platform inovatif untuk membantu menjaga kesehatan mental, fisik, dan keamanan siswa di lingkungan sekolah. Di web ini, kami menggabungkan berbagai fitur *wellness* (kesejahteraan) dalam satu tempat yang interaktif dan mudah diakses.

## 🚀 Cara Menjalankan Web Ini (Cara Pakai)

Untuk mencoba dan menilai web ini, Bapak/Ibu Juri tidak perlu repot menginstal *software* atau *server* tambahan. Web ini dibangun murni menggunakan HTML, CSS, dan JavaScript biasa.

**Langkah-langkah pengujian:**
1. Pastikan semua file proyek sudah berada di dalam satu folder.
2. Cari file utama yang bernama `index.html`.
3. Cukup klik dua kali (double-click) pada file `index.html` tersebut.
4. Web akan langsung terbuka dan siap dinavigasikan melalui browser bawaan (misal: Google Chrome, Firefox, atau Edge).

*Catatan tambahan: Jika Bapak/Ibu Juri terbiasa mengecek kode menggunakan VS Code, web ini juga sangat kompatibel untuk dijalankan menggunakan ekstensi **Live Server**.*

## 🌟 Fitur-Fitur Unggulan Web

Kami menyediakan berbagai fitur interaktif untuk menunjang kesejahteraan siswa. Berikut adalah halaman-halaman yang bisa Bapak/Ibu Juri jelajahi:

- **Beranda Utama:** Pusat navigasi web dengan desain modern dan ramah pengguna untuk menyambut pengunjung.
- **Latihan Pernapasan:** Fitur relaksasi interaktif yang memandu ritme napas, cocok untuk membantu siswa menenangkan diri saat stres atau cemas.
- **Layanan Konseling:** Tempat untuk mencari informasi seputar layanan bimbingan konseling di sekolah.
- **Materi Edukasi:** Kumpulan bacaan untuk menambah wawasan siswa seputar kesehatan mental dan fisik.
- **Manajemen Waktu Gadget:** Fitur untuk membantu memantau dan membatasi *screen time* agar siswa tidak kecanduan gadget.
- **Pengingat Hidrasi:** Fitur untuk mencatat dan mengingatkan siswa agar rajin minum air putih setiap harinya.
- **Pola Tidur:** Panduan untuk membantu siswa mengatur jadwal tidur agar mendapatkan istirahat yang berkualitas.
- **Sistem Pelaporan:** Saluran aman bagi siswa untuk melaporkan kendala, perundungan (bullying), atau hal darurat di lingkungan sekolah.

## 🛠️ Informasi Teknis (Struktur File)

Jika Bapak/Ibu Juri ingin meninjau kode sumber yang kami buat, setiap halaman pada website memiliki folder tersendiri yang berisi file HTML, CSS, dan JavaScript yang digunakan pada halaman tersebut.

Struktur proyek dirancang agar lebih terorganisir dan mudah ditelusuri.

Contoh struktur:

```text
project/
│
├── index.html
│
├── pages/
│   ├── counseling/
│   │   ├── counseling.html
│   │   ├── counseling.css
│   │   └── counseling.js
│   │
│   ├── breathing/
│   │   ├── breathing.html
│   │   ├── breathing.css
│   │   └── breathing.js
│   │
│   ├── hydration/
│   │   ├── hydration.html
│   │   ├── hydration.css
│   │   └── hydration.js
│   │
│   └── ...
│
└── PAGE_DESIGN.md
```

### Cara Meninjau Kode

* File **HTML** digunakan untuk struktur halaman.
* File **CSS** digunakan untuk desain dan tampilan visual.
* File **JavaScript** digunakan untuk logika, animasi, dan interaktivitas fitur.

Untuk melihat kode suatu fitur, Bapak/Ibu Juri cukup membuka folder halaman yang ingin diperiksa. Seluruh file yang berkaitan dengan halaman tersebut tersedia di dalam folder yang sama sehingga lebih mudah untuk ditinjau.

Selain itu, dokumen **PAGE_DESIGN.md** disertakan sebagai referensi tambahan mengenai konsep desain dan pengembangan website.
